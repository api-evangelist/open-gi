# Open GI

> Open GI is a Worcester-headquartered insurance software house that has supplied the UK and Ireland general insurance market for more than 45 years, serving over 600 broker, MGA and insurer customers across personal and commercial lines. Its product estate spans the legacy Core policy administration system and the cloud Mobius platform. Open GI's API surface is real but entirely partner/customer-gated: Mobius ships APIs (a Client Checks / sanctions-check API and an API-triggered custom event, plus an SME property owners quote API on the Core side), all consumed through a Mobius Developer Portal whose URL Open GI does not publish. There is no public self-serve developer portal, no downloadable OpenAPI, no public sandbox and no published authentication model.

## APIs

- [Mobius APIs](https://www.opengi.co.uk/mobius-release): The API layer of Open GI's cloud Mobius broking platform. Evidenced only by Open GI's public release notes: a Client Checks API (POST to initiate a sanction check for a customer, GET endpoints for automated and manual sanction-check matches, GET for the detail of a specific sanction, POST to update notes and overridden matches) and the ability to trigger a Mobius custom event from an external system via an API call. Access is gated through the Mobius Developer Portal; no base URL, OpenAPI definition, authentication scheme, rate limits or sandbox are publicly documented.

## Access and gating

- The Mobius Developer Portal is referenced in Open GI's own release notes and platform-services terms but its URL is never published publicly.
- No developer, developers, docs, api, apis, portal, partners or mobius subdomain resolves under opengi.co.uk. A certificate-transparency sweep returned 38 hostnames with no developer-, docs-, api- or portal-named host among them.
- Every developer-shaped path on the marketing site (/developers, /developer, /developer-portal, /api, /apis, /partners, /integrations) returns HTTP 404.
- The API Terms of Use page and the Mobius Platform Services terms page are both Webflow password-protected (HTTP 401).
- Insurer connectivity is delivered through UK-market EDI messaging inside the platform and through pre-agreed Partner Network integrations (150+ insurers, aggregators, premium finance, payment and data-enrichment providers) rather than an open API programme.
